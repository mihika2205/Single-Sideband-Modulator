SSB Modulation using NGSpice & KiCad
A simulation-based implementation of a Single Sideband Suppressed Carrier (SSB-SC) Communication System using NGSpice and KiCad/eSim. This project focuses on understanding practical analog communication concepts such as modulation, filtering, waveform analysis, and signal recovery through circuit simulation.

# Project Overview
Single Sideband (SSB) modulation is an advanced form of amplitude modulation widely used in communication systems due to its improved bandwidth and power efficiency. In SSB-SC, only one sideband is transmitted while the carrier signal is suppressed, reducing unnecessary power transmission and spectrum usage.
This project demonstrates the design and simulation of an SSB modulation system using open-source EDA tools. The implementation includes generation of message and carrier signals, modulation stages, filtering, waveform analysis, and output observation using transient simulation.

# Simulation & Analysis
The project was simulated using transient analysis to observe:
Message Signal
Carrier Signal
Modulated Output Signal
Filtered Output Waveform
Different simulation approaches and configurations were explored during implementation. Some predefined behavioral models produced compatibility and parsing issues during simulation, so alternative circuit configurations were implemented to obtain stable output waveforms successfully.
